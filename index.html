PDF-Kompressor

Stack: Python, Flask, PyMuPDF (fitz), Supabase (PostgreSQL)

Hosting: Render (Web Service), Supabase (Datenbank)

Funktionsweise: Der Nutzer lädt eine PDF-Datei hoch und wählt eine Qualitätsstufe (in Prozent). Das Backend öffnet die PDF mit PyMuPDF, rendert jede Seite als Rasterbild (Pixmap) mit der gewählten Skalierung und erstellt ein neues PDF aus den komprimierten Bildern. Dabei werden Garbage Collection (Stufe 4), Deflate-Kompression für Bilder, Schriften und Streams angewandt. Die komprimierte Datei wird direkt als Download zurückgegeben — es werden keine Dateien auf dem Server gespeichert. Zusätzlich verfügt die App über ein Feedback-System (Like/Dislike) mit Supabase-Datenbank (PostgreSQL) und IP-basierter Duplikaterkennung — jeder Nutzer kann nur einmal abstimmen, seine Stimme ändern oder zurücknehmen.

GitHub: pdf-compressor-web →

Foto zu PDF

Stack: Python, Streamlit, Pillow (PIL)

Hosting: Streamlit Community Cloud (Snowflake)

Funktionsweise: Der Nutzer wählt ein oder mehrere Fotos (JPG/PNG) über den Datei-Upload aus. Die Bilder werden mit Pillow in den RGB-Modus konvertiert und anschließend mit der Methode Image.save() zu einer mehrseitigen PDF-Datei zusammengefügt — jedes Foto wird zu einer eigenen Seite. Die gesamte Verarbeitung erfolgt im Arbeitsspeicher (BytesIO), ohne Dateien auf dem Server zu speichern. Nach der Erstellung wird das PDF als Vorschau im Browser angezeigt (Base64-iframe) und kann direkt heruntergeladen werden. Eine Miniaturansicht aller hochgeladenen Fotos wird in einem 4-Spalten-Raster dargestellt.
