а) Необходимые (всегда активны)

Следующие данные технически необходимы и не требуют согласия:

Правовая основа: ст. 6 абз. 1 лит. f DSGVO, § 25 абз. 2 № 2 TDDDG (технически необходимо для предоставления функции, явно запрошенной пользователем).

Без вашего согласия эти данные не сохраняются в памяти вашего браузера. Контент (погода, курс и т. д.) будет отображаться в текущем сеансе, но не будет кэшироваться. При переходе между страницами данные будут запрашиваться заново через наши серверные прокси.

б) Техническая обработка через серверный прокси
Запросы к API Groq выполняются исключительно на стороне сервера через нашу собственную прокси-конечную точку (Vercel Serverless Function /api/chat). В Groq передаются только содержание вашего сообщения, до 20 предыдущих сообщений текущей беседы (для сохранения контекста), языковая версия сайта (de/ru), а также IP-адрес нашего серверного прокси. На нашем сервере (Vercel) сообщения чата и история чата не сохраняются. Сервер выступает исключительно в роли временного прокси: запрос обрабатывается и сразу передаётся дальше в Groq. Никакие данные чата на наших серверах не хранятся.

в) Содержание сообщений — Уведомление
Мы настоятельно рекомендуем не вводить персональные данные (например, полное имя, адрес, номер телефона, дату рождения, данные о здоровье, банковские реквизиты) и любую конфиденциальную информацию в чат. Если вы все же введете персональные данные в чат, они будут переданы в Groq Inc. в США.

г) Нулевое хранение данных (Zero Data Retention - ZDR) и минимизация данных
В наших настройках API активирована функция «Inference APIs ZDR». Тем самым мы реализуем свое право на Opt-Out (отказ): ваши вводы и выводы не протоколируются на постоянной основе и не сохраняются на 30 дней компанией Groq, а обрабатываются только на время генерации ответа. Кроме того, запросы к API не используются для обучения ИИ-моделей. В данном случае Groq выступает исключительно в роли обработчика данных (Data Processor).

д) Локальное сохранение истории чата в браузере (Session Storage)
Чтобы ваша история чата сохранялась при переходе между отдельными страницами сайта во время текущего сеанса браузера, до 20 последних сообщений вашей беседы сохраняются в Session Storage вашего браузера (ключ: dmd_chat_history). 20. Обзор локально сохраненных данных (Local Storage / Session Storage)

Этот веб-сайт не использует классические HTTP-файлы cookie. Вместо этого в памяти вашего браузера сохраняются следующие данные (в зависимости от вашего согласия):

Local Storage (постоянно, до ручного удаления):

• silktideCookieChoice_*, silktideCookieBanner_InitialChoice — Настройки согласия для Cookie-баннера (Silktide). Необходимые.

• cookieConsent (значение: accepted или rejected) — собственный статус согласия (Storage Guard). Необходимые.
