PDF-компрессор

Стек: Python, Flask, PyMuPDF (fitz), Supabase (PostgreSQL)

Хостинг: Render (Web Service), Supabase (база данных)

Принцип работы: Пользователь загружает PDF-файл и выбирает уровень качества (в процентах). Бэкенд открывает PDF с помощью PyMuPDF, рендерит каждую страницу как растровое изображение (Pixmap) с выбранным масштабом и создаёт новый PDF из сжатых изображений. При этом применяются Garbage Collection (уровень 4), Deflate-сжатие для изображений, шрифтов и потоков. Сжатый файл возвращается напрямую как загрузка — на сервере файлы не сохраняются. Дополнительно приложение имеет систему отзывов (Like/Dislike) с базой данных Supabase (PostgreSQL) и распознаванием дубликатов по IP — каждый пользователь может проголосовать только один раз, изменить свой голос или отозвать его.

Фото в PDF

Стек: Python, Streamlit, Pillow (PIL)

Хостинг: Streamlit Community Cloud (Snowflake)

Принцип работы: Пользователь выбирает одно или несколько фото (JPG/PNG) через загрузку файлов. Изображения конвертируются в режим RGB с помощью Pillow и затем объединяются методом Image.save() в многостраничный PDF-файл — каждое фото становится отдельной страницей. Вся обработка выполняется в оперативной памяти (BytesIO), без сохранения файлов на сервере. После создания PDF отображается как предпросмотр в браузере (Base64-iframe) и может быть напрямую загружен. Миниатюры всех загруженных фото отображаются в сетке из 4 столбцов.
