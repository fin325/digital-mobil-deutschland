📄 PDF-компрессор

Стек: Python, Flask, PyMuPDF (fitz), Supabase (PostgreSQL)

Хостинг: Render (Web Service), Supabase (база данных)

Принцип работы: Пользователь загружает PDF-файл и выбирает уровень качества (в процентах). Бэкенд открывает PDF с помощью PyMuPDF, рендерит каждую страницу как растровое изображение (Pixmap) с выбранным масштабированием и создаёт новый PDF из сжатых изображений. При этом применяются сборка мусора (уровень 4), Deflate-сжатие для изображений, шрифтов и потоков. Сжатый файл возвращается напрямую для скачивания — файлы на сервере не сохраняются. Дополнительно приложение имеет систему обратной связи (лайк/дизлайк) с базой данных Supabase (PostgreSQL) и определением дубликатов по IP — каждый пользователь может проголосовать только один раз, изменить или отозвать свой голос.

📸 Фото в PDF

Стек: Python, Streamlit, Pillow (PIL)

Хостинг: Streamlit Community Cloud (Snowflake)

Принцип работы: Пользователь выбирает одно или несколько фото (JPG/PNG) через загрузку файлов. Изображения конвертируются с помощью Pillow в режим RGB и затем объединяются методом Image.save() в многостраничный PDF-файл — каждое фото становится отдельной страницей. Вся обработка происходит в оперативной памяти (BytesIO), без сохранения файлов на сервере. После создания PDF отображается в виде предварительного просмотра в браузере (Base64-iframe) и может быть сразу скачан. Миниатюры всех загруженных фото отображаются в сетке из 4 столбцов.
