📄 Сжатие PDF

Стек: Python, Flask, PyMuPDF (fitz), Supabase (PostgreSQL)

Хостинг: Render (Web Service), Supabase (База данных)

Как это работает: Пользователь загружает PDF-файл и выбирает уровень качества (в процентах). Бэкенд открывает PDF с помощью PyMuPDF, рендерит каждую страницу как растровое изображение (Pixmap) с выбранным масштабированием и создает новый PDF из сжатых изображений. При этом применяются сборка мусора (уровень 4), Deflate-сжатие для изображений, шрифтов и потоков. Сжатый файл возвращается напрямую для скачивания — файлы на сервере не сохраняются. Дополнительно приложение имеет систему отзывов (Лайк/Дизлайк) с базой данных Supabase (PostgreSQL) и определением дубликатов по IP — каждый пользователь может проголосовать только один раз, изменить свой голос или отозвать его.

📸 Фото в PDF

Стек: Python, Streamlit, Pillow (PIL)

Хостинг: Streamlit Community Cloud (Snowflake)

Как это работает: Пользователь выбирает одну или несколько фотографий (JPG/PNG) через загрузку файлов. Изображения конвертируются в режим RGB с помощью Pillow, а затем объединяются в многостраничный PDF-файл с помощью метода Image.save() — каждая фотография становится отдельной страницей. Вся обработка происходит в оперативной памяти (BytesIO) без сохранения файлов на сервере. После создания PDF отображается как превью в браузере (Base64-iframe) и может быть сразу скачан. Миниатюры всех загруженных фотографий отображаются в сетке из 4 колонок.
